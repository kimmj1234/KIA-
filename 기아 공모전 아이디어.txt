============================================================
 Pleos Mate 기획서
 현대자동차그룹 차량용 앱 개발 공모전 출품작
============================================================


1. 문제 정의
------------------------------------------------------------

차량은 이동 수단이지만, 그 안에서 운전자가 아닌 사람의 시간은
충분히 활용되지 못하고 있다.

- 이동 중: 운전자는 운전에 집중하지만, 옆좌석과 뒷좌석 동승자는
  스마트폰만 보거나 무료하다. 특히 가족과의 장거리 이동에서
  차 안 경험은 단절되어 있다.

- 충전 중: 전기차 충전은 보통 20~40분이 소요된다. 이 시간 동안
  운전자와 동승자 모두 차 안에서 특별히 할 일이 없다.

- 안전: 운전자는 화면을 볼 수 없어, 기존 차량 앱의 대부분 기능을
  주행 중 사용할 수 없다.

- 연결: 각자의 차로 이동하는 가족과 지인은 서로의 상황을 알기 어렵다.

즉, 차량 안의 빈 시간과 비운전자의 경험이 활용되지 못하고 있으며,
운전자와 동승자, 차량과 차량 사이의 연결도 부족하다.


2. 솔루션
------------------------------------------------------------

Pleos Mate는 차량 데이터와 연동하여 이동 중과 충전 중의 빈 시간을
가치 있게 만들고, 운전자와 동승자, 차량과 차량을 연결하는
차량용 통합 엔터테인먼트 플랫폼이다.

한 줄 정의: "말 한마디로 차가 내가 원하는 공간이 된다."

핵심 원칙:
- 운전자는 안전하게: 운전자 대상 콘텐츠는 음성과 청각 중심으로 설계한다.
- 동승자는 몰입하게: 동승자는 게임, 미디어, 노래방 등에 몰입한다.
- 온 가족은 안심하게: 아이와 반려동물을 동의 기반으로 모니터링한다.
- 지인과는 가볍게 연결되게: 자동 연결이 아닌 자동 제안과 수락
  방식으로 연결한다.


3. 핵심 기능
------------------------------------------------------------

3.1 음성 단축어 (메인 기능)
............................................................

차량 내부 AI에게 사용자가 지정한 이름의 명령을 말하면,
미리 설정한 여러 기능이 한 번에 작동한다.

[음성 명령 예시]

  "사일런스 모드 실행해줘"
    -> 창문 닫기, 선팅 단계 최대, 지정 노래 재생, 실내 조명 어둡게

  "아이 재우기 실행해줘"
    -> 실내 조명 최소, 동화 읽어주기 시작, 공조 조용히, 창문 닫기

  "충전 모드 실행해줘"
    -> 노래방 모드 진입, MR 대기, 충전량 표시, 조명 변경

  "여행 시작 실행해줘"
    -> 목적지 경로 안내, 여행 라디오 시작, 동승자 대시보드 켜기

  "반려동물 모드 실행해줘"
    -> 내부 카메라 모니터링, 실내 온도 조절, 음악 재생

설계 포인트:
- 사용자 정의 매크로: 명령어 이름과 실행할 기능을 직접 조합한다.
  창문, 선팅, 음악, 조명, 공조, 카메라, 모드 전환 등을 포함한다.
- 음성 인식: 등록된 명령어만 작동하여 오인식을 방지한다.
- 안전 가드: 주행 중 위험한 기능은 제한하고, 중요한 기능은
  음성 확인 후 작동한다.
- 추천 매크로: 사용 패턴을 학습하여 매크로를 추천한다.
- 공유: 가족끼리 매크로를 공유할 수 있다.

차량 데이터: 음성 인식, 창문, 선팅, 조명, 공조 제어, 미디어 재생, 모드 전환


3.2 노래방 모드 (메인 기능)
............................................................

블루투스 마이크에 들어온 목소리를 차량 스피커로 실시간 출력하여
실제 노래방과 같은 연출을 제공한다.

- 실시간 모니터링: 마이크 입력에 이펙트를 적용한 뒤 차량 스피커로
  출력한다. 지연을 최소화한다.
- 보컬 이펙트: 에코, 리버브, 오토튠을 프리셋 또는 슬라이더로 조절한다.
- MR 재생: 곡 선택 시 반주를 재생하고 원곡과 반주를 전환한다.
- 보컬과 반주 믹스: 보컬 볼륨과 반주 볼륨을 각각 조절한다.
- 다중 마이크: 마이크 두 개를 연결하여 듀엣이 가능하고
  좌석별 볼륨을 조절한다.
- 차량 스피커 활용: 다채널 스피커로 공간감 있는 연출을 제공한다.
- 녹음과 공유: 부른 노래를 녹음하여 공유한다. 동의 기반으로 한다.
- 게이미피케이션: 점수와 박자 정확도를 표시하고 충전량과 연동한
  미션을 제공한다.
- 안전 장치: 정차와 충전 중에는 전체 기능을 제공하고, 주행 중에는
  오디오 중심과 볼륨 제한을 적용한다.

차량 데이터: 마이크 연결 상태, 오디오 시스템, 충전 상태, 정차 상태


3.3 이동 모드
............................................................

- 협동 게임: 동승자끼리 즐기는 초경량 게임으로, 속도, 정체, 날씨,
  남은 이동 시간을 게임 변수로 활용한다.
- 여행 라디오: 내비게이션 경로와 주변 명소 데이터를 읽어
  지역 이야기, 퀴즈, 추천 음식을 큐레이션한다.
- 동승자 대시보드: 뒷좌석 승객이 공조, 음악, 남은 시간을 확인하고
  제어한다.

차량 데이터: 남은 이동 시간, 속도, 정체 여부, GPS 위치,
주변 관심지점, 날씨


3.4 미디어 모드
............................................................

- 동승자 전용 화면: 운전자는 내비게이션을 보는 동안 동승자는
  별도 화면에서 유튜브와 OTT를 시청한다.
- 차량 최적화 시청: 주행 중에는 오디오 중심, 정차와 충전 중에는
  영상 전체 화면으로 자동 전환한다.
- 계정 연동과 미러링: 사용자 계정 또는 스마트폰 미러링으로
  재생하며, 저작권은 플랫폼 정책을 준수한다.

차량 데이터: 주행 상태, 화면 분할, 오디오 제어


3.5 게임 모드
............................................................

- 블루투스 게임패드와 조이스틱 연결을 감지하여 자동으로
  게임 모드에 진입한다.
- 접근 경로는 세 가지로 구분한다.
  (1) 리모트 플레이와 미러링: 스마트폰과 콘솔 화면을
      차량 스크린으로 표시한다.
  (2) 클라우드 게이밍: 제휴 클라우드 게이밍 서비스를 연동한다.
  (3) 차량 최적화 캐주얼 게임: 자체 또는 제휴 캐주얼 게임을 제공한다.
- 충전 중에는 충전량과 연동한 미션을 제공하고, 정체 중에는
  미니게임을 제공한다.
- 패드를 여러 개 연결하여 동승자끼리 대전과 협동이 가능하다.

차량 데이터: 충전 상태, 정체 여부, 블루투스 연결 상태,
오디오 시스템, 화면 분할


3.6 키즈 모드
............................................................

- 읽어주기: 동화와 책을 차량 스피커로 읽어준다.
- 그림책 모드: 화면에 그림책 페이지를 표시하고 페이지 넘김에 맞춰
  읽어준다.
- 취침 모드: 조명, 음악, 읽기 속도를 조절하여 수면 환경을 만든다.
- 부모 음성 녹음: 부모가 미리 녹음한 목소리로 읽어준다.
- 이동 시간 연동: 남은 시간에 맞춰 동화 편수를 자동 매칭한다.

차량 데이터: 남은 이동 시간, 충전 상태, 실내 조명, 오디오


3.7 안심 모드
............................................................

- 동의 기반 녹화: 탑승자 전원의 동의 후 작동하며, 녹화 중임을
  화면에 표시한다.
- 아이와 반려동물 모니터링: 뒷좌석 상태를 보호자 스마트폰으로
  확인한다. 주행 중 운전자에게는 음성 알림만 제공한다.
- 로컬 저장 기본: 영상은 차량 내에 저장하고 외부 전송은
  사용자가 선택한 경우에만 한다.
- 이벤트 감지: 급제동과 충돌 시 자동으로 녹화한다.
- 프라이버시: 녹화 일시정지와 자동 삭제 주기를 설정한다.

차량 데이터: 내부 카메라, 충돌과 급제동 센서, 저장 공간


3.8 연동 모드
............................................................

- 화면 미러링: 노트북과 태블릿 화면을 유선 또는 무선으로
  차량 스크린에 표시한다.
- 자유 플레이: 사용자가 원하는 게임, 영상, 업무 화면을
  차량 스크린에서 그대로 즐긴다.
- 화면 분할: 운전자 내비게이션과 동승자 미러링 화면을
  동시에 표시한다.
- 게임패드 연동: 블루투스 패드와 결합하여 태블릿 게임을
  차량 스크린과 패드로 즐긴다.

차량 데이터: 화면 분할, 주행 상태, 블루투스 연결


3.9 충전 모드
............................................................

- 충전 게이미피케이션: 배터리 충전량과 연동한 미니 게임을
  제공하고, 충전 완료 시 보상을 제공한다.
- 충전소 주변 탐험: 충전소 위치 데이터를 활용하여 주변 맛집,
  카페, 명소를 지도로 탐험한다.
- 짧은 학습: 충전 시간에 맞춘 5분과 10분 단위 오디오 콘텐츠를
  제공한다.

차량 데이터: 배터리 충전 상태, 예상 충전 완료 시간,
충전소 위치, 주변 관심지점


3.10 운전자 모드
............................................................

운전자는 전방 주시가 최우선이므로 음성과 청각 중심으로 설계한다.

- 오디오 퀴즈: 경로와 주변 명소, 음악, 안전 상식 퀴즈를 음성으로
  출제하고 음성으로 응답한다.
- 안전 운전 게이미피케이션: 급제동, 급가속, 과속을 분석하여
  안전 운전 점수와 배지를 제공한다. 연속 안전 운전 기록과
  가족 리더보드를 제공한다.
- 대화 콘텐츠: 오늘의 질문 카드, 여행 스토리텔링, 목적지 미션을
  음성으로 제공한다.
- 주차 후 콘텐츠: 주차 완료 후 짧은 두뇌 게임을 제공한다.
- 드라이브 리포트: 주행 거리, 안전 점수, 함께 들은 음악,
  방문 지역을 요약하여 공유한다.

차량 데이터: 주행 데이터, 내비게이션, 속도, 위치


3.11 메이트 콜
............................................................

지인끼리 서로를 등록해두면, 차량이 근처에 있거나 특정 조건에서
자동으로 음성 연결을 제안한다.

작동 흐름:
(1) 사전 등록: 가족, 친구, 동료를 메이트로 등록한다.
    서로 동의한 상대만 연결 가능하다.
(2) 연결 트리거: 근접 감지, 경로 교차, 시간 약속 중
    사용자가 설정한 조건에서 제안한다.
(3) 안전 알림: 짧은 신호음을 먼저 재생하고 차량 스크린에
    연결 여부를 표시한다.
(4) 수락과 거절: 음성 또는 버튼으로 선택한다.
    거절 시 상대에게 알림이 가지 않는다.
(5) 연결: 수락 시 음성 통화를 시작한다. 주행 중에는 오디오 중심,
    정차와 충전 중에는 화면 통화가 가능하다.
(6) 자동 종료: 목적지 도착, 속도 변화, 사용자 요청 시 종료한다.

안전과 프라이버시 설계:
- 자동 연결이 아니라 자동 제안 후 수락 방식으로 운영한다.
- 주행 중 수락은 음성으로만 가능하며 화면 조작을 최소화한다.
- 통화 중에도 내비게이션 음성 안내를 우선하고 통화 볼륨을
  자동 조절한다.
- 위치는 근처에 있음 정도만 공유하고 정확한 좌표는 공유하지 않는다.
- 운전 집중 모드 설정 시 연결 제안 자체를 차단한다.

차량 데이터: GPS, 속도, 주행 상태, 음성 인식, 오디오 시스템

5. 차별점
------------------------------------------------------------

(1) 비운전자 중심: 기존 차량 앱은 운전자 중심이나, Pleos Mate는
    동승자와 대기자를 1차 사용자로 설정한다.

(2) 음성 단축어: 말 한마디로 여러 기능을 한 번에 실행하는
    차량용 매크로를 제공한다. 화면을 보지 않아도 되어
    운전 집중도를 높인다.

(3) 실제 노래방 연출: 블루투스 마이크 입력을 차량 스피커로
    출력하여 차 안을 노래방으로 만든다.

(4) 이동과 충전의 통합: 두 시나리오를 하나의 앱으로 묶어
    차량 안의 빈 시간을 일관되게 활용한다.

(5) 안전 중심 설계: 운전자 콘텐츠는 음성 중심, 화면 콘텐츠는
    정차와 충전 중으로 한정한다.

(6) 동의 기반 안심 모니터링: 내부 카메라와 녹화는 동의 기반으로
    운영하고 로컬 저장을 기본으로 한다.

(7) 부담 없는 연결: 메이트 콜은 자동 제안 후 수락 방식으로
    운영하고 거절 시 상대에게 알리지 않는다.


6. 기대 효과
------------------------------------------------------------

[사용자]
- 이동과 충전 중 지루함을 해소하고 동승자와의 유대를 형성한다.
- 음성 단축어로 운전 중에도 안전하게 차량 기능을 제어한다.
- 아이와 반려동물을 안심하고 모니터링한다.

[현대자동차]
- Pleos 앱 마켓의 앱 다양성을 확대한다.
- 가족과 동승자 중심의 차량 경험으로 차별화한다.
- 충전 생태계와 주변 서비스 연계 가능성을 확보한다.
- 음성 단축어와 메이트 콜을 통해 차량 간 연결 서비스의
  기반을 마련한다.


7. 실행 계획
------------------------------------------------------------

(1) 기획: 본 기획서로 공모전에 접수하고 사용자 시나리오와
    화면 흐름도를 작성한다.

(2) 프로토타입: 기존 게임 제작 경험을 바탕으로 이동 모드 협동 게임과
    음성 단축어 설정 화면의 웹 프로토타입을 제작한다.
    차량 데이터는 모의 데이터로 대체한다.

(3) 확장: Pleos SDK와 API를 학습한 뒤 실제 차량 데이터를 연동한다.

프로토타입 참고: 기존 게임 제작 작업물을 기획서에 첨부하여
실행 역량을 보여준다.


8. 안전 및 정책 고려 사항
------------------------------------------------------------

- 운전자 대상 콘텐츠는 음성과 청각 중심으로 제공하고,
  화면 시청은 정차와 충전 중으로 한정한다.
- 노래방 모드는 주행 중 볼륨을 제한하고 정차와 충전 중
  전체 기능을 제공한다.
- 내부 카메라 녹화는 탑승자 전원의 동의 기반으로 운영하고
  로컬 저장을 기본으로 한다.
- 메이트 콜은 자동 연결이 아닌 자동 제안 후 수락 방식으로 운영한다.
- OTT와 MR 콘텐츠는 사용자 계정 연동, 미러링, 제휴를 전제로 하며
  앱은 차량 최적화 레이어 역할을 한다.
- 게임 콘솔과 스토어 콘텐츠는 리모트 플레이, 클라우드 게이밍,
  캐주얼 게임의 세 경로로 접근한다.


9. 향후 확장 아이디어
------------------------------------------------------------

- AI 습관 학습: 음성 단축어 사용 패턴을 학습하여 사용자가
  말하기 전에 매크로를 제안한다.
- 로드 커뮤니티: 같은 도로를 달리는 차량끼리 익명으로
  교통 정보를 음성으로 공유한다.
- 이동 기반 기부: 에코 드라이빙 점수를 사회 공헌 기부로 연결한다.
- 시니어 모드: 큰 글씨와 느린 음성 안내로 어르신 운전자를 배려한다.
- 주차 후 나만의 시간: 명상, 오디오북, 음성 일기 콘텐츠를 제공한다.
- 경로 기반 자동 촬영: 경치 좋은 지점에서 촬영을 제안하고
  가족 드라이브 앨범을 자동 생성한다.
